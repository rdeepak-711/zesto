Design — Unified FSM with Capability Flags

Service Orders + Appointment Booking for salons, generic for all business types

1. Capability Flags on Tenant

// New columns on tenants table
hasCart     Boolean @default(true)   // can browse+order items
hasBooking  Boolean @default(false)  // booking step after checkout
hasEnquiry  Boolean @default(false)  // custom product enquiry flow
hasDelivery Boolean @default(true)   // collect address + delivery date

// Presets (no code change needed for new types)
Bakery:      hasCart=✓ hasDelivery=✓
Salon:       hasCart=✓ hasBooking=✓ hasDelivery=✗
Photo Studio: hasEnquiry=✓ hasCart=✗
Spa/Clinic:  hasCart=✓ hasBooking=✓ hasDelivery=✗

2. New Booking Table

model Booking {
  id            String        @id @default(uuid())
  tenantId      String?
  orderId       String        @unique // 1:1 with Order
  customerPhone String
  customerName  String
  customerAge   Int
  preferredDate String        // "2026-05-20"
  preferredTime String        // "afternoon" or "3pm"
  confirmedDate String?       // set by owner
  confirmedTime String?
  status        BookingStatus @default(PENDING)
  createdAt     DateTime      @default(now())
  updatedAt     DateTime      @updatedAt
}
